# 02. 트랜잭션 및 롤백 검증

## 목적
주문 처리 중 오류가 발생하면 재고 변경까지 취소되는지 확인했습니다.

## 진행 방식
1. `BEGIN`으로 트랜잭션을 시작했습니다.
2. 상품 재고를 1개 차감했습니다.
3. 주문 수량에 `-1`을 넣어 오류를 발생시켰습니다.
4. `ROLLBACK`으로 작업을 취소했습니다.
5. 재고와 주문상세 데이터를 다시 조회했습니다.

잘못된 수량을 입력했을 때 **CHECK 오류(SQLSTATE 23514)**가 발생했습니다.

> 오류를 발생시키는 [테스트 SQL](../sql/03b_failed_order_test.sql)은 단계별로 실행해야 합니다. 오류가 발생한 뒤에는 `ROLLBACK`을 실행해야 합니다.

## 결과 및 배운 점
롤백 후 재고가 원래 값으로 돌아오고, 잘못된 주문상세가 저장되지 않은 것을 확인했습니다.

여러 테이블을 함께 변경하는 작업에서는 오류가 발생했을 때 **변경 사항을 함께 취소하는 것**이 중요하다는 점을 배웠습니다.
