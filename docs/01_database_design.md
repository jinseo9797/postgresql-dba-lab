# 01. 데이터베이스 설계 및 무결성 검증

## 목적
고객, 상품, 주문, 주문상세, 재고를 각각 관리하고 잘못된 데이터 입력을 막기 위해 테이블을 설계했습니다.

## 진행 방식
`ecommerce` 스키마에 다음 테이블을 만들었습니다.

| 테이블 | 주요 내용 |
|---|---|
| `customers` | 고객 ID, 이메일 |
| `products` | 상품 ID, 가격 |
| `orders` | 고객별 주문 |
| `order_items` | 주문별 상품과 수량 |
| `inventory` | 상품별 재고 |

- 기본키(PK)와 외래키(FK)로 테이블 관계를 구성했습니다.
- 고객 이메일에는 `UNIQUE`를 적용했습니다.
- 가격과 재고는 음수가 되지 않도록 `CHECK`를 설정했습니다.
- 주문 수량은 0보다 커야 하도록 설정했습니다.

## 결과 및 배운 점
회원·상품·주문 데이터를 연결하는 구조를 만들고, 잘못된 주문 수량이 입력될 때 제약조건 오류가 발생하는 것을 확인했습니다.
